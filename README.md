# RAG-Simple-Chat 🤖

Учебный прототип RAG-системы (Retrieval-Augmented Generation) для ответов на вопросы по базе знаний. Проект демонстрирует полный цикл создания AI-сервиса: от работы с локальными моделями до развертывания API.

🛠 Стек технологий

LLM: llama3.2:1b (локальный запуск через Ollama)
Embeddings: nomic-embed-text (через Ollama)
Векторная база: Qdrant (in-memory)
Фреймворк: LangChain
API: FastAPI (эндпоинт /ask)
⚙️ Как это работает

Chunking: Текст базы знаний разбивается на небольшие фрагменты.
Embeddings: Каждый фрагмент превращается в вектор с помощью nomic-embed-text.
Vector Search: При вопросе пользователя система ищет наиболее похожие по смыслу фрагменты в базе Qdrant.
Generation: Найденные фрагменты передаются в LLM (llama3.2:1b), и модель генерирует ответ, основанный на этих фактах.
API: Вся логика обернута в FastAPI, что позволяет обращаться к RAG-системе по HTTP-запросу.
🚀 Запуск

Для запуска откройте файл RAG_Qdrant_FastAPI.ipynb в Google Colab.
Примечание: Для работы требуется запущенный сервер Ollama с моделями llama3.2:1b и nomic-embed-text. В Colab сервер запускается через colab-xterm.

💡 Особенности реализации

В проекте продемонстрирован полный цикл работы с LLM: от установки движка Ollama до построения пайплайна RAG с использованием локальных моделей (без затрат на API OpenAI) и создания REST API на FastAPI.
