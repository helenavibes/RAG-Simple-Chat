# RAG-Simple-Chat 🤖

Учебный прототип RAG-системы (Retrieval-Augmented Generation) для ответов на вопросы по базе знаний.

## 🛠 Стек технологий
*   **LLM:** `llama3.2:1b` (локальный запуск через Ollama)
*   **Embeddings:** `nomic-embed-text` (через Ollama)
*   **Векторная база:** FAISS
*   **Фреймворк:** LangChain

## ⚙️ Как это работает
1.  **Chunking:** Текст базы знаний разбивается на небольшие фрагменты.
2.  **Embeddings:** Каждый фрагмент превращается в вектор с помощью `nomic-embed-text`.
3.  **Vector Search:** При вопросе пользователя, система ищет наиболее похожие по смыслу фрагменты в базе FAISS.
4.  **Generation:** Найденные фрагменты передаются в LLM (`llama3.2:1b`), и модель генерирует ответ, основанный на этих фактах.

## 🚀 Запуск
Для запуска откройте файл `.ipynb` в Google Colab. 
*Примечание:* Для работы требуется запущенный сервер Ollama с моделями `llama3.2:1b` и `nomic-embed-text`.

## 💡 Особенности реализации
В проекте продемонстрирован полный цикл работы с LLM: от установки движка Ollama до построения пайплайна RAG с использованием локальных моделей (без затрат на API OpenAI).
